Coordinates without guesswork.

Text tools speak several coordinate systems. Denebola keeps them on the same immutable value and rejects positions that split a codepoint or surrogate pair.

Bring your own summary.

The rope is built on a generic persistent B+ tree. Give each item an immutable summary, then seek through any monotone dimension.

  • Updates copy touched paths and share the rest.
  • Nodes cache cumulative summaries and item counts.
  • Cursors seek by bytes, characters, UTF-16, lines, or your own dimension.
tree = Denebola::Tree.new(items, summary: Weight)
tree = tree.push(next_item)

cursor = tree.cursor(:weight).seek(42)
cursor.item
cursor.summary # everything before item

Start with one require.

Install the gem, create a rope, and keep any version you still need. Every edit returns a new frozen value.

View on RubyGems 
gem install denebola
require "denebola"

rope = Denebola::Rope.new("hello\nworld")
snapshot = rope
rope = rope.insert(5, ", there")

snapshot.to_s # "hello\nworld"
rope.to_s     # "hello, there\nworld"
